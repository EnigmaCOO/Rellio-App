# GEMINI Playbook — client

## Purpose
Help Gemini craft guidance for the React/Vite frontend that delivers the immersive, voice-ready scripture and persona experience.

## How to Work with Requests
1. Identify the feature area (landing, auth, persona selection, verse browsing, voice chat, reflections).
2. Map UI changes to the appropriate source areas: components, hooks/lib, pages, assets, or public files.
3. Keep mobile-first, accessible, and brand-aligned execution in view for every recommendation.

## Execution Steps
- Suggest how to compose pages from existing modules while keeping logic in hooks/lib and presentation in components.
- Note data needs and API touchpoints with the backend and shared schemas.
- Flag performance, accessibility, and voice-interaction considerations relevant to the requested update.

## Completion Checklist
- Clear routing or component targets identified.
- Data and dependency requirements documented.
- UX, accessibility, and performance impacts acknowledged.
