# GEMINI Playbook — client/src

## Purpose
Help Gemini deliver actionable guidance for the TypeScript/React source that powers scripture browsing, persona chat, and voice interactions.

## How to Work with Requests
1. Identify whether the change touches routing/pages, components, hooks, or lib utilities.
2. Align data needs with backend APIs and shared schemas, noting any typing or validation updates.
3. Keep mobile-first, accessible, and performant design as default constraints.

## Execution Steps
- Recommend where logic should live (hooks/lib) versus UI composition (components/pages).
- Describe state management or data fetching patterns that keep the experience responsive and voice-ready.
- Call out testing expectations (unit/integration) and TypeScript strictness for any new code paths.

## Completion Checklist
- Clear file targets and ownership noted.
- Data flow and dependency implications described.
- Accessibility, performance, and testing considerations included.
