# GEMINI Playbook — client/src/tests

## Purpose
Equip Gemini to outline frontend testing strategies that validate components, hooks, and pages for the Rellio experience.

## How to Work with Requests
1. Identify the feature under test (chat, voice hooks, persona UI, pages, utilities).
2. Choose appropriate test levels (unit, integration, UI) and tools consistent with the project setup.
3. Cover accessibility, state management, and async flows where relevant.

## Execution Steps
- Propose test cases, fixtures, and mocks that mirror scripture/AI/voice scenarios.
- Highlight assertions for rendering states, interactions, and error handling.
- Include guidance on running tests with existing scripts and keeping them deterministic.

## Completion Checklist
- Test scope and tools defined.
- Key scenarios and assertions listed.
- Notes provided on handling async/voice/WebSocket behaviors.
