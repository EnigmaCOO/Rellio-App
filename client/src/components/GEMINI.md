# GEMINI Playbook — client/src/components

## Purpose
Provide Gemini with direction for building React components that realize Rellio’s immersive scripture, persona, chat, and progress experiences.

## How to Work with Requests
1. Determine the feature module involved (IlluminVerse, chat, auth, profile, progress, UI primitives).
2. Separate presentation from logic—components stay declarative while hooks/lib carry data and state work.
3. Maintain responsiveness, accessibility, and brand consistency for every component.

## Execution Steps
- Suggest props, composition patterns, and motion/accessibility considerations relevant to the requested UI.
- Note data dependencies and how components should interface with hooks or context.
- Highlight reuse opportunities across modules to keep the design system cohesive.

## Completion Checklist
- Component scope and hierarchy clarified.
- Props and state expectations aligned with hooks/lib.
- Accessibility and responsive behavior documented.
