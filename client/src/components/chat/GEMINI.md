# GEMINI Playbook — client/src/components/chat

## Purpose
Guide Gemini in shaping chat UI components that connect users with persona-driven, voice-enabled conversations while reading.

## How to Work with Requests
1. Identify whether the task involves message display, composer controls, persona presence, or voice indicators.
2. Align UX with live voice flows and cross-faith comparison needs.
3. Keep accessibility (keyboard, screen readers) and latency awareness in mind.

## Execution Steps
- Outline component responsibilities, props, and how they integrate with chat/voice hooks.
- Suggest layouts for message threads, persona avatars, and comparison callouts.
- Recommend micro-interactions (typing states, streaming responses) that respect mobile constraints.

## Completion Checklist
- Clear mapping to supporting hooks/state.
- Voice and persona cues represented in the UI plan.
- Accessibility and performance considerations captured.
