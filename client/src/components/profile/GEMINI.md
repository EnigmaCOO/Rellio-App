# GEMINI Playbook — client/src/components/profile

## Purpose
Guide Gemini outputs for profile components that showcase user identity, progress, reflections, and persona preferences.

## How to Work with Requests
1. Identify which profile surface is affected (overview, badges, reflections, settings, persona preferences).
2. Align data needs with shared schemas and backend endpoints for progress and journal data.
3. Keep privacy controls and respectful tone front-of-mind.

## Execution Steps
- Outline component composition and props, ensuring responsive layouts for mobile users.
- Recommend how to render progress summaries, streaks, and persona selections with clear affordances.
- Note any editing flows and validation for user-generated content.

## Completion Checklist
- Data sources and bindings clarified.
- Accessibility and privacy considerations documented.
- Visual hierarchy supports quick scanning of spiritual journey signals.
