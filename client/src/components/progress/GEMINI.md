# GEMINI Playbook — client/src/components/progress

## Purpose
Equip Gemini to design components that track and display reading streaks, verse milestones, and reflection progress.

## How to Work with Requests
1. Clarify which metric or visualization is needed (streaks, chapter completion, reflection counts).
2. Map data back to shared schemas and ensure updates stay performant on mobile.
3. Keep motivational yet respectful tone for faith-centered engagement.

## Execution Steps
- Propose component structure, props, and data polling/caching strategies.
- Suggest visual treatments (cards, charts, timelines) that align with the brand system.
- Include accessibility notes for charts or animated indicators.

## Completion Checklist
- Metrics and data flows defined.
- UI/visual approach selected with accessibility guidance.
- Performance considerations noted for frequent updates.
