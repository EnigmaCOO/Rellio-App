- Show:

  - Time spent in different personas or traditions (if enabled).
- Encourage **gentle, non-gamified motivation** aligned with spiritual depth, not “points chasing”.

## Key Tasks for Agents
- Build dashboards that communicate **growth, consistency, and balance**, without inducing pressure.
