# GEMINI Playbook — client/src/components/IlluminVerse

## Purpose
Support Gemini in crafting components for the IlluminVerse visual layer—ambient, persona-aligned environments that react to user reading and chat.

## How to Work with Requests
1. Clarify which scene or persona environment needs updating and what triggers its transitions.
2. Note performance budgets for animations on mobile devices.
3. Ensure visuals reinforce the respectful, multi-faith atmosphere.

## Execution Steps
- Recommend component boundaries and props for controlling backgrounds, lighting, and motion states.
- Describe how to hook into app state (persona selection, reading progress, voice status) to drive visual changes.
- Suggest asset usage from `public/images` or `client/public/assets` and fallback behavior for low-power modes.

## Completion Checklist
- Scene triggers and data dependencies identified.
- Animation/performance guidelines documented.
- Asset references and accessibility considerations included.
