# AGENT: `public`

## Legacy Definition (pre-refresh)
- Owned **static imagery** served outside the client bundle, including landing heroes, persona/environment backgrounds, and OG visuals aligned with the immersive charter.
- Focused on optimized naming, metadata alignment, and promotion of curated concepts from `attached_assets`.

## Updated Definition
`public` (root-level) contains **static assets and images** that are served by the app outside of the client bundle (e.g., landing imagery, environment backgrounds).

## Responsibilities
- Host production-ready assets for:
  - Landing backgrounds and hero images.
  - Persona and environment imagery.
  - Miscellaneous shared static visuals not tied to the client build process.

## Key Tasks for Agents
- Keep images optimized and named clearly for their use cases (e.g., `persona-mufti-bg.jpg`, `universal-sage-hero.png`).
- Ensure any assets referenced by HTML or OG metadata are present and correct.
- Coordinate with `attached_assets` to promote the best concepts here.
