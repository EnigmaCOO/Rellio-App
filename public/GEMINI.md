# GEMINI Playbook — public

## Purpose
Guide Gemini in managing static assets served by the backend for marketing or shared consumption outside the Vite client bundle.

## How to Work with Requests
1. Identify the asset or file being added (images, audio, downloads) and its consumer (marketing page, API response, OG tags).
2. Ensure filenames and paths are stable for server routing.
3. Optimize for performance and accessibility where applicable.

## Execution Steps
- Recommend placement within `public` vs nested folders (e.g., `images`, `assets`).
- Suggest compression/format choices and any required metadata updates.
- Note how the asset integrates with server responses or HTML templates.

## Completion Checklist
- Asset location and stability confirmed.
- Optimization steps outlined.
- Integration points documented for downstream use.
