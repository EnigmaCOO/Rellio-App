Implement “Verse Spotlight” Card on Welcome Screen

Goal: Enhance the landing/welcome screen (displayed before any scripture is selected) by adding a futuristic “Verse Spotlight” card that dynamically cycles through random verses from all supported texts (Qur’an, Bible, Torah, Gita, Tarpatika). The card must show the verse reference, text, and a concise AI-generated insight. Use a white background with neon accents for a modern, engaging look. Reference the attached wireframe for visual design: dark navy card with neon-turquoise text, circular refresh button at bottom-left, and thin progress bar at bottom.

Tech Stack Assumptions:

React for UI (use functional components with hooks).
Tailwind CSS for styling (or your existing framework; no inline CSS).
Existing API endpoints for scriptures (e.g., /api/verse/random) and AI Scholar (/api/scholar/explain).
No additional dependencies unless specified (e.g., if needed, suggest Heroicons for icons).

On load or refresh, randomly select a religion/text (Bible, Qur’an, Torah, Gita, Hadith) and fetch a random verse.
Fetch details:

Reference (e.g., “Matthew 5:9” or “Qur’an 2:255”).
API Call Example: GET /api/verse/random?faith=random (return { faith, book, chapter, verse, text }).
Error Handling: If fetch fails, show a fallback verse from local mock data (e.g., pre-load 5 sample verses).

Expect response: { "insight": "One–two sentence explanation emphasizing key theme." }
Fallback: If API fails, use a template like "This verse from [faith] highlights [theme], encouraging [action]."
