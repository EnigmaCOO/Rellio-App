# GEMINI Playbook — attached_assets

## Purpose
This folder is the design and reference vault for Rellio. Gemini responses should help curate and describe non-production assets that guide the visual direction for the app.

## How to Work with Requests
1. Start by confirming the requested asset theme (persona, background, OG image, etc.) and whether it is reference-only or destined for production export.
2. Describe organization: group or rename items into clear subfolders (e.g., personas, backgrounds, og_images, icons) with concise notes on intended usage.
3. When adding notes, emphasize how each asset supports the immersive, multi-faith, voice-enabled experience outlined in the blueprint.

## Execution Steps
- Suggest folder structure and file naming that makes it obvious where assets are used downstream (public/images, client/public/assets, client/src/assets).
- Provide short captions or README snippets indicating how and where a notable asset should be used in the product.
- Flag deprecated or experimental pieces so implementers know whether to promote, refine, or archive them.

## Completion Checklist
- Assets grouped by theme with clear names.
- Usage notes added for any hero or persona-defining pieces.
- References to promotion paths (where the optimized versions should live) are documented.
