# GEMINI Playbook — attached_assets/generated_images

## Purpose
Guide Gemini outputs for managing AI-generated and experimental visuals that seed production-ready assets.

## How to Work with Requests
1. Clarify the experiment focus (persona portrait, environment, hero art) and intended destination if promoted.
2. Recommend grouping images by experiment or persona (e.g., mufti_v1, universal_sage_bg_round2).
3. Capture any prompt snippets or generation notes that future iterations should know.

## Execution Steps
- Propose lightweight README entries noting intended usage for promising images and whether they have production successors.
- Mark which assets should be promoted to public/images or client/src/assets and note the target format/size.
- Suggest cleanup actions while preserving a small archive of past directions for reference.

## Completion Checklist
- Experiments organized by persona or theme.
- Notes include usage intent and prompt highlights where helpful.
- Promotion status and next steps are clearly called out.
