Bootstrap a production-ready monorepo with web (React/Three.js), server (Node/Express), real-time voice (WS), AI adapters (Grok/GPT), Drizzle ORM (Neon Postgres), Redis, and a secure baseline. If an existing file conflicts, overwrite it.

0) High-Level Objectives
	•	Build Rellio: a multi-faith spiritual sanctuary fusing cinematic 3-D immersion, elite, interruptible voice UX, and a learning/community ecosystem.
	•	Deliver: web app, API server, WS voice, DB schema+migrations+seed, auth, AI persona system, scripture connectors, 3-D scene with lip-sync, Security P0, CI/CD, tests (vitest + Cypress), metrics, GDPR, offline PWA, haptics, AR/VR scaffolds, zip export, and Postman.

1) Tech Stack (with realistic scaling)
	•	Monorepo: pnpm workspaces, TypeScript strict, Turbo.
	•	Frontend: React 18 + Vite, Tailwind + shadcn/ui, Framer Motion, react-three-fiber/Three.js + @react-three/drei, React Query, Zustand.
	•	3-D: GLTFLoader, Mixamo animations, phoneme→viseme adapter (Rhubarb compatible).
	•	Voice: /ws/voice (ws), ElevenLabs Realtime primary; Web Speech API fallback; navigator.vibrate for haptics.
	•	Backend: Node 20, Express, ws, Drizzle + Neon Postgres, Redis, zod, jose (JWT), pino, bullmq (background jobs).
	•	AI: XAI Grok-2 primary; OpenAI GPT-4o fallback via unified adapter; HuggingFace Inference for lightweight personalization/sentiment.
	•	Security: helmet + strict CSP, CORS allowlist, DOMPurify server-side, xss, multer, rate-limiter-flexible.
	•	Ops/QA: ESLint/Prettier, vitest, Cypress e2e, GitHub Actions (build+lint+test).
	•	Offline: PWA (manifest + service worker via Workbox); IndexedDB cache for scriptures.
	•	XR (scaffolds): AR.js (AR) and A-Frame (VR) routes (disabled by default behind feature flags).

4) Server (apps/server)

Install: express, ws, cors, helmet, compression, pino(+pretty), zod, jose, bcryptjs, rate-limiter-flexible, drizzle-orm, pg, postgres, ioredis, nanoid, xss, multer, @huggingface/inference, bullmq.

Key folders
	•	src/voice/ws.ts — WS handler (hello, heartbeats, interrupt, relay to ElevenLabs RT; stop current stream on new “interrupt” message).
	•	src/ai/adapter.ts — Grok primary / OpenAI fallback + persona guards.
	•	src/ml/personalize.ts — sentiment + path suggestion.
	•	src/scripture/providers/* — Bible/Quran/Torah/Gita/Tripitaka adapters (normalized).
	•	src/security/* — CSP + rate limit.
	•	src/routes/* — health, chat, compare, progress, gdpr (consent CRUD), metrics (server events).

Schema (Drizzle, excerpt)
	•	users, messages, progress, bookmarks, consents, metrics_events.

Routes
	•	GET /health
	•	POST /api/chat { persona, text, context? }  → JSON (SSE stream optional)
	•	POST /api/compare { topic|verseRef, targets[] }
	•	GET /api/scripture/:faith/:book/:chapter
	•	POST /api/progress
	•	POST /api/ml/path (queue personalization job)
	•	POST /api/gdpr/consent { region, accepted }
	•	WS /ws/voice (JSON control + binary chunks, heartbeats)

Helmet with strict CSP, rate limit (IP + token bucket), server-side sanitize, zod validation, JWT rotation (short access, refresh rotate+revoke), WS heartbeats+idle kill, pino redaction.
Docs: docs/SECURITY_P0.md.
